# Jules Agent Instructions

## Перед началом работы

1. Прочитай этот файл и `docs/ARCHITECTURE.md`.
2. Затем изучи `docs/CODEBASE_MEMORY.md`, если файл присутствует. Это автоматически сгенерированный архитектурный срез, построенный по графу связей проекта.
3. Сверяй документацию с фактическим кодом: описания могут отставать от реализации.

## Карта проекта

- `src/main.rs` — точка входа приложения.
- `src/lib.rs` — библиотечный корень и публичная организация модулей.
- `src/sim/` — симуляция мира, события, пространственный индекс и бой.
- `src/ai/` — тактический, торговый и стратегический ИИ, а также личности.
- `src/render/` — камера, отображение галактики и кораблей, меню, UI и частицы.
- `src/ship.rs` — модульная физика кораблей и структурная целостность.
- `src/economy.rs`, `src/traders.rs`, `src/factions.rs`, `src/galaxy.rs`, `src/items.rs` — предметные подсистемы.
- `scripts/` — Lua-данные и скрипты для игровых сущностей и поведения.
- `tests/` — интеграционные тесты.

## Правила изменений

- Сохраняй существующую модульную архитектуру и минимизируй область изменений.
- Не добавляй новые зависимости без необходимости; при добавлении обновляй `Cargo.toml` и `Cargo.lock`.
- Для изменений поведения добавляй или обновляй тесты.
- Не редактируй `docs/CODEBASE_MEMORY.md` вручную: он обновляется GitHub Actions.
- Перед завершением выполни `cargo fmt --all -- --check`, `cargo check --all-targets` и `cargo test --all-targets`, если окружение поддерживает сборку.
- В итоговом описании укажи изменённые файлы, проверки и возможные ограничения.
